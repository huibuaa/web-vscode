# Web-VSCode

[English](README.md) | [简体中文](README.zh-CN.md)

An open-source VS Code extension that brings AI-assisted coding into your editor: streaming chat, inline completion, and context-menu actions powered by OpenAI-compatible APIs (DeepSeek, OpenAI, etc.).

> **Status:** v0.0.1 — actively developed. RAG-based knowledge retrieval and cross-task orchestration are on the roadmap.

---

## Features

### Chat & Sessions

- Sidebar chat panel with **streaming responses**
- Markdown code-block rendering in replies
- **Multi-session** history with persistence across restarts
- In-panel **settings** (API URL, API Key, model, completion options)
- **i18n** — UI follows VS Code display language (EN / zh-CN)

### Inline Completion

- AI inline completion for all file types
- Configurable auto-trigger and max token length
- Uses editor context (lines before cursor) for suggestions

### Editor Context Menu

Select code → right-click **Web-VSCode AI Assistant**:

| Action | Description |
|--------|-------------|
| Open Chat | Focus the sidebar chat panel |
| Explain Code | Explain the selected code |
| Analyze Use Cases | Analyze inputs, outputs, edge cases, and exceptions |
| Generate Comments | Generate commented code; **one-click insert** into editor |
| Generate Unit Tests | Generate unit tests for the selection |
| Fix Bugs | Find and suggest fixes for bugs |

## Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [VS Code](https://code.visualstudio.com/) ≥ 1.108.1

### Install & Run (Development)

```bash
git clone https://github.com/huibuaa/web-vscode.git
cd web-vscode
npm install
npm run compile
```

Press **F5** in VS Code to launch **Extension Development Host**, then:

1. Open the **Web-VSCode AI** icon in the activity bar
2. Click **Settings** (gear) in the chat header
3. Fill in your **API Key** and save
4. Start chatting or use the editor context menu on selected code

### Configuration

| Setting | Key | Default |
|---------|-----|---------|
| API URL | `web-vscode.apiUrl` | `https://api.deepseek.com/v1` |
| API Key | `web-vscode.apiKey` | _(empty)_ |
| Model | `web-vscode.model` | `deepseek-chat` |
| Auto Completion | `web-vscode.autoTriggerCompletion` | `true` |
| Completion Max Tokens | `web-vscode.completionMaxTokens` | `256` |

Configure via chat panel settings, VS Code Settings UI, or `settings.json`.

## Scaffolding vs Extension

This repo combines the **official VS Code extension scaffold** with **custom AI features**. Understanding the split helps contributors navigate the codebase.

### From Scaffold (`yo code` / `@vscode/generator-code`)

Generated by the official generator with **TypeScript + Webpack**:

| Item | Purpose |
|------|---------|
| `webpack.config.js` | Bundle `src/` → `dist/extension.js` |
| `tsconfig.json` | TypeScript compiler options |
| `eslint.config.mjs` | ESLint flat config |
| `.vscode/launch.json` | F5 debug (Extension Development Host) |
| `.vscode/tasks.json` | Watch / build tasks |
| `.vscode/extensions.json` | Recommended extensions |
| `.vscode-test.mjs` | Test runner config |
| `src/test/extension.test.ts` | Placeholder test suite |

**npm scripts from scaffold:**

```bash
npm run compile    # webpack build
npm run watch      # webpack watch mode
npm run package    # production bundle
npm run lint       # eslint src
npm run test       # vscode-test
```

### Custom Extension (Project-Specific)

Business logic built on top of the scaffold:

```
src/
├── extension.ts                 # Entry: register providers & commands
├── commands/register-commands.ts
├── providers/
│   ├── chat-webview-provider.ts # Sidebar chat + sessions + streaming
│   └── completion-provider.ts   # Inline completion
├── services/ai-service.ts       # OpenAI-compatible API (stream & non-stream)
├── chat/
│   ├── session-manager.ts       # Multi-session logic
│   └── session-store.ts         # Persist sessions (globalState)
├── webview/chat-panel.ts        # Chat UI (HTML/CSS/JS)
├── config/settings.ts           # Read/write VS Code settings
├── i18n/ui-strings.ts           # Localized UI strings
├── prompts/l10n-prompts.ts      # Localized editor action prompts
├── constants/index.ts
└── types/
resources/
├── l10n/                        # Extension l10n bundles
├── assets/images/icon.svg       # Activity bar icon
package.nls.json                 # Localized package.json strings
package.nls.zh-cn.json
```

**Runtime dependency:** [axios](https://github.com/axios/axios) — HTTP client for AI API calls.

## Architecture Overview

```
User
 ├── Sidebar Chat (Webview)  ──► ChatViewProvider ──► AiService (stream)
 ├── Inline Completion       ──► CompletionProvider ──► AiService (non-stream)
 └── Context Menu Commands   ──► register-commands ──► ChatViewProvider
                                      │
                                      ▼
                              OpenAI-compatible API
                              POST /chat/completions
```

**Streaming:** Chat uses `stream: true` + SSE parsing. Inline completion uses one-shot responses.

**Planned:** RAG-based standard knowledge retrieval; automated result handoff between tasks (e.g. generated code → test generation).
